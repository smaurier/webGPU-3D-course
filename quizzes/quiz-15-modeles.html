Quiz 15 — Modeles et animations

1. Pourquoi glTF est-il le format recommande pour le web 3D ?

Correct ! glTF (GL Transmission Format) est le "JPEG de la 3D" : format ouvert, compact (GLB binaire), avec PBR, animations, squelettes, et des donnees directement exploitables par le GPU sans conversion.
Incorrect. glTF est recommande car il est compact, supporte le PBR/animations/squelettes, et ses donnees sont directement exploitables par le GPU.

2. A quoi sert AnimationMixer dans Three.js ?

Correct ! AnimationMixer gere le playback des AnimationClips pour un objet. Il permet de jouer, pauser, crossfader et blender plusieurs animations. On l'update avec mixer.update(delta) dans la boucle.
Incorrect. AnimationMixer gere la lecture et le melange des animations (AnimationClips) d'un objet 3D.

3. Quel est le role de DRACOLoader ?

Correct ! DRACOLoader decode les geometries compressees avec Google Draco (extension KHR_draco_mesh_compression dans glTF). La compression reduit la taille des mesh de 50-90% avec une perte negligeable.
Incorrect. DRACOLoader decode les geometries compressees Draco dans les fichiers glTF, offrant une reduction de taille de 50-90%.

4. Quel est l'avantage de InstancedMesh par rapport a cloner un mesh ?

Correct ! InstancedMesh rend N instances en 1 draw call. On definit la matrice de chaque instance via setMatrixAt(i, matrix). C'est ideal pour les forets, particules, foules, etc.
Incorrect. InstancedMesh dessine toutes les instances en un seul draw call avec une geometrie et un materiau partages, bien plus performant que des clones separees.

5. Que sont les morph targets (blend shapes) ?

Correct ! Les morph targets stockent des positions alternatives pour les sommets. On interpole entre la forme de base et les targets via des poids (0 a 1), ideal pour les expressions faciales ou deformations douces.
Incorrect. Les morph targets sont des positions de sommets alternatives qu'on interpole pour deformer le mesh (expressions faciales, muscles, etc.).
