Quiz 06 — WebGL fondamentaux

1. A quoi sert le qualificateur precision mediump float; en GLSL ES ?

Correct ! En WebGL, le fragment shader n'a pas de precision par defaut pour les floats. precision mediump float; fixe la precision a 16 bits, un bon compromis performance/qualite.
Incorrect. precision mediump float; definit la precision par defaut des flottants dans le fragment shader (obligatoire en WebGL car il n'y a pas de defaut).

2. Quelles sont les deux etapes de la compilation d'un shader en WebGL ?

Correct ! On compile d'abord chaque shader individuellement avec gl.compileShader(), puis on les lie dans un programme avec gl.linkProgram().
Incorrect. Les shaders sont d'abord compiles individuellement (gl.compileShader), puis lies dans un programme (gl.linkProgram).

3. Quelle est la difference entre gl.drawArrays et gl.drawElements ?

Correct ! drawElements utilise un index buffer (ELEMENT_ARRAY_BUFFER) pour referencer les sommets par index, evitant de dupliquer les sommets partages entre triangles.
Incorrect. drawElements utilise un index buffer pour reutiliser les sommets partages, ce qui reduit la memoire et ameliore les performances sur les maillages complexes.

4. Comment obtient-on un contexte WebGL a partir d'un canvas ?

Correct ! On utilise canvas.getContext('webgl') pour WebGL 1 ou canvas.getContext('webgl2') pour WebGL 2. La methode retourne null si le contexte n'est pas supporte.
Incorrect. On obtient le contexte via canvas.getContext('webgl') ou canvas.getContext('webgl2').

5. Que fait gl.enable(gl.DEPTH_TEST) ?

Correct ! gl.enable(gl.DEPTH_TEST) active le test de profondeur. Sans cela, les objets sont dessines dans l'ordre des appels draw, sans tenir compte de leur distance a la camera.
Incorrect. gl.enable(gl.DEPTH_TEST) active le z-buffer pour que les fragments les plus proches masquent ceux qui sont derriere.
