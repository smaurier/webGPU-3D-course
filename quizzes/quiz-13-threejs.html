Quiz 13 — Three.js fondamentaux

1. Quels sont les trois elements minimum pour afficher quelque chose avec Three.js ?

Correct ! Le trio fondamental est : une Scene (conteneur de tous les objets), une Camera (point de vue), et un WebGLRenderer (qui effectue le rendu dans un canvas).
Incorrect. Les trois elements minimum sont : Scene (contient les objets), Camera (point de vue), et Renderer (dessine le resultat).

2. Que fournit OrbitControls dans Three.js ?

Correct ! OrbitControls permet de manipuler la camera avec la souris : clic gauche pour orbiter, molette pour zoomer, clic droit pour le pan. Il faut appeler controls.update() dans la boucle de rendu si enableDamping est active.
Incorrect. OrbitControls fournit un controle interactif de camera (rotation orbitale, zoom, pan) via les evenements souris/tactile.

3. Quelle est la difference entre Geometry et BufferGeometry dans Three.js ?

Correct ! L'ancienne classe Geometry (supprimee en r125) utilisait des objets JavaScript. BufferGeometry stocke les donnees dans des BufferAttribute (Float32Array), beaucoup plus performant car directement envoyable au GPU.
Incorrect. BufferGeometry utilise des typed arrays (Float32Array) pour les donnees de sommets, ce qui est bien plus performant que l'ancien Geometry (supprime) qui utilisait des objets JS.

4. Qu'est-ce que MeshStandardMaterial ?

Correct ! MeshStandardMaterial est le materiau PBR de Three.js, utilisant le workflow metalness/roughness. Il supporte les textures (map, normalMap, roughnessMap, metalnessMap, aoMap, emissiveMap, etc.).
Incorrect. MeshStandardMaterial est le materiau PBR de Three.js avec les proprietes metalness et roughness, offrant un rendu physiquement realiste.

5. Pourquoi la boucle de rendu Three.js utilise-t-elle requestAnimationFrame ?

Correct ! requestAnimationFrame synchronise avec le VSync de l'ecran, met en pause automatiquement quand l'onglet est cache, et fournit un timestamp precis pour les animations.
Incorrect. requestAnimationFrame synchronise le rendu avec le rafraichissement ecran, pause quand l'onglet est masque, et evite le tearing.
