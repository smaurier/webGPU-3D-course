Quiz 11 — Compute shaders

1. Que definit @workgroup_size(64) dans un compute shader WGSL ?

Correct ! @workgroup_size(64) definit que chaque workgroup contient 64 invocations (threads). Le nombre total de threads est workgroup_size * nombre de workgroups dispatches.
Incorrect. @workgroup_size definit le nombre de threads par workgroup. Le nombre total de threads depend aussi du nombre de workgroups dispatches.

2. Que represente @builtin(global_invocation_id) ?

Correct ! global_invocation_id = workgroup_id * workgroup_size + local_invocation_id. C'est l'index global unique de chaque thread, utilise pour adresser les donnees dans les buffers.
Incorrect. Le global_invocation_id est l'identifiant unique global du thread, calcule comme workgroup_id * workgroup_size + local_invocation_id.

3. Quelle est la difference entre un uniform buffer et un storage buffer en WebGPU ?

Correct ! Les uniform buffers sont read-only et limites a 64 Ko (minUniformBufferOffsetAlignment). Les storage buffers supportent read/write, sont beaucoup plus grands, mais avec un acces potentiellement moins rapide.
Incorrect. Les storage buffers sont read/write et de grande taille, tandis que les uniform buffers sont read-only et limites a 64 Ko minimum garanti.

4. Comment lance-t-on un compute shader en WebGPU ?

Correct ! On cree un compute pass via commandEncoder.beginComputePass(), on set le pipeline et les bind groups, puis on appelle dispatchWorkgroups(x, y, z) pour lancer la grille de workgroups.
Incorrect. On lance un compute shader via computePass.dispatchWorkgroups(x, y, z) apres avoir configure le pipeline et les bind groups.

5. A quoi sert un staging buffer en WebGPU ?

Correct ! Un staging buffer (avec usage MAP_READ | COPY_DST) sert d'intermediaire pour lire les resultats GPU cote CPU. On copie du buffer GPU vers le staging buffer, puis on mappe le staging buffer pour le lire.
Incorrect. Un staging buffer est un buffer intermediaire (MAP_READ + COPY_DST) qui permet de lire les donnees GPU cote CPU, car les buffers GPU ne sont pas directement accessibles.
