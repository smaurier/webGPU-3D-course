Quiz 00 — Prerequis et introduction

1. Quelle est la principale difference architecturale entre un CPU et un GPU ?

Correct ! Le GPU est concu avec des milliers de coeurs simples pour le parallelisme massif (SIMD), alors que le CPU a quelques coeurs complexes optimises pour les taches sequentielles.
Incorrect. Le GPU possede des milliers de coeurs simples optimises pour le calcul parallele (SIMD), contrairement au CPU qui a peu de coeurs complexes pour le sequentiel.

2. En quelle annee WebGL 1.0 a-t-il ete officiellement publie ?

Correct ! WebGL 1.0 a ete publie en 2011 par le Khronos Group, base sur OpenGL ES 2.0.
Incorrect. WebGL 1.0 a ete publie en 2011 par le Khronos Group.

3. Qu'est-ce que le parallelisme de type SIMD ?

Correct ! SIMD (Single Instruction, Multiple Data) signifie qu'une meme instruction est appliquee simultanement a plusieurs donnees, ce qui est le mode de fonctionnement principal du GPU.
Incorrect. SIMD signifie Single Instruction, Multiple Data : une meme instruction appliquee a plusieurs donnees en parallele.

4. Qu'est-ce que la VRAM ?

Correct ! La VRAM (Video RAM) est la memoire dediee au GPU, avec une bande passante elevee optimisee pour les acces paralleles massifs.
Incorrect. La VRAM est la memoire dediee au GPU, optimisee pour les acces paralleles avec une bande passante elevee.

5. A quoi sert requestAnimationFrame dans le contexte du rendu 3D ?

Correct ! requestAnimationFrame synchronise le callback de rendu avec le rafraichissement de l'ecran (generalement 60 Hz), evitant le tearing et optimisant les performances.
Incorrect. requestAnimationFrame sert a synchroniser la boucle de rendu avec le taux de rafraichissement de l'ecran pour un rendu fluide.
