Quiz 22 — Modelisation 3D

1. Quel raccourci Blender permet d'entrer en mode edition ?

Correct ! Tab bascule entre le mode Object et le mode Edit. En mode Edit, on peut manipuler les sommets, aretes et faces individuellement.
Incorrect. Tab est le raccourci pour basculer entre le mode Object et le mode Edit dans Blender.

2. Qu'est-ce que le UV unwrapping ?

Correct ! L'UV unwrapping deplie la surface 3D du mesh en coordonnees 2D (U, V). On place des seams (coutures) pour guider le depliage, puis chaque face est mappee sur l'espace texture [0,1]x[0,1].
Incorrect. L'UV unwrapping deplie la surface 3D en une carte 2D definissant la correspondance entre les faces du modele et les coordonnees de texture.

3. Quelles sont les bonnes pratiques pour exporter en glTF depuis Blender ?

Correct ! Bonnes pratiques : Apply All Transforms (Ctrl+A), materiaux Principled BSDF (directement mappes vers glTF PBR), export GLB binaire, Draco pour la compression, verifier les normales et les UVs.
Incorrect. Il faut appliquer les transformations, utiliser Principled BSDF, exporter en GLB et optionnellement activer la compression Draco.

4. Qu'est-ce que le baking en modelisation 3D ?

Correct ! Le baking projette les details d'un mesh haute resolution (sculpt) en textures (normal map, AO, curvature) utilisables sur un mesh basse resolution, conservant l'apparence detaillee avec peu de polygones.
Incorrect. Le baking transfere les details d'un modele high-poly en textures (normal map, AO) pour un modele low-poly, conservant l'apparence avec moins de polygones.

5. Quel est un budget polycount raisonnable pour un objet web 3D interactif ?

Correct ! Pour le web : hero objects 10-50k tris, props secondaires 1-5k tris, arriere-plan <1k tris. Budget total scene : 100k-500k tris selon la cible (mobile vs desktop). Les draw calls comptent autant que les polygones.
Incorrect. Un budget raisonnable est 1k-50k tris par objet et 100k-500k tris total pour la scene, en ciblant un bon compromis qualite/performance web.
