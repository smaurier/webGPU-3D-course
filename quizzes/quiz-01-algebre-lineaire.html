Quiz 01 — Algebre lineaire

1. Que retourne le produit scalaire (dot product) de deux vecteurs perpendiculaires ?

Correct ! Le dot product de deux vecteurs perpendiculaires vaut 0, car a . b = |a| * |b| * cos(90) = 0.
Incorrect. Le dot product de deux vecteurs perpendiculaires vaut 0, car le cosinus de 90 degres est 0.

2. Que produit le produit vectoriel (cross product) de deux vecteurs ?

Correct ! Le cross product retourne un vecteur perpendiculaire au plan defini par les deux vecteurs d'entree, dont la norme est |a| * |b| * sin(theta).
Incorrect. Le cross product produit un vecteur perpendiculaire au plan forme par les deux vecteurs d'entree.

3. Pourquoi utilise-t-on des coordonnees homogenes (vec4) en 3D ?

Correct ! Les coordonnees homogenes (w=1 pour les points, w=0 pour les directions) permettent d'encoder la translation dans une matrice 4x4, unifiant toutes les transformations affines en multiplications matricielles.
Incorrect. Les coordonnees homogenes permettent de representer les translations comme des multiplications matricielles, unifiant toutes les transformations en une seule matrice 4x4.

4. Comment les matrices sont-elles stockees en memoire en WebGL/OpenGL ?

Correct ! WebGL/OpenGL utilise le format column-major. La matrice est stockee colonne par colonne dans un tableau lineaire de 16 floats.
Incorrect. WebGL/OpenGL stocke les matrices en column-major (colonne par colonne) dans un Float32Array de 16 elements.

5. Quelle est la condition pour pouvoir multiplier une matrice A (m x n) par une matrice B (p x q) ?

Correct ! Le nombre de colonnes de A (n) doit etre egal au nombre de lignes de B (p). Le resultat est une matrice m x q.
Incorrect. Pour A(m x n) * B(p x q), il faut que n = p. Le resultat est une matrice de dimension m x q.
