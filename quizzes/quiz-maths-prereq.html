Quiz Maths — Prerequis mathematiques

1. Que retourne lerp(a, b, 0.25) avec a=0 et b=100 ?

Correct ! lerp(0, 100, 0.25) = 0 + 0.25 * (100 - 0) = 25. L'interpolation lineaire retourne la valeur a 25% du chemin entre a et b.
Incorrect. lerp(a, b, t) = a + t * (b - a), donc 0 + 0.25 * 100 = 25. La reponse est 25.

2. Combien de radians font 180 degres ?

Correct ! 180 degres = pi radians. La formule de conversion est : radians = degres * pi / 180.
Incorrect. 180 degres correspond a pi radians. Un tour complet (360 degres) = 2 * pi radians.

3. Sur le cercle unite, quelles sont les coordonnees du point a un angle de 90 degres (pi/2 radians) ?

Correct ! A pi/2, cos(pi/2) = 0 et sin(pi/2) = 1, donc le point est (0, 1).
Incorrect. Sur le cercle unite, un point a l'angle theta a pour coordonnees (cos(theta), sin(theta)). A pi/2 : (0, 1).

4. Dans un triangle rectangle avec des cotes de longueur 3 et 4, quelle est la longueur de l'hypotenuse ?

Correct ! Par le theoreme de Pythagore : sqrt(3^2 + 4^2) = sqrt(9 + 16) = sqrt(25) = 5.
Incorrect. Le theoreme de Pythagore donne c = sqrt(a^2 + b^2) = sqrt(9 + 16) = 5. C'est le triplet pythagoricien classique (3, 4, 5).

5. Quel est le produit scalaire (dot product) de (1, 0, 0) et (0, 1, 0) ?

Correct ! Le dot product de deux vecteurs perpendiculaires est 0. 1*0 + 0*1 + 0*0 = 0.
Incorrect. dot((1,0,0), (0,1,0)) = 1*0 + 0*1 + 0*0 = 0. Deux vecteurs orthogonaux ont toujours un dot product nul.
