Quiz 20 — Physique

1. Quels sont les trois types de rigid body dans un moteur physique ?

Correct ! Dynamic : soumis a la gravite et aux forces. Kinematic : deplace par le code, pousse les dynamic mais n'est pas affecte par eux. Static : immobile (sol, murs), infinite mass.
Incorrect. Les trois types sont : Dynamic (soumis aux forces), Kinematic (controle par code), et Static (immobile).

2. Quelle est la phase de broad phase dans la detection de collisions ?

Correct ! La broad phase utilise des AABB (Axis-Aligned Bounding Boxes) et des structures spatiales (BVH, grille) pour rapidement eliminer les paires qui ne se chevauchent pas, avant la narrow phase couteuse.
Incorrect. La broad phase filtre rapidement les paires d'objets via des volumes englobants (AABB) pour reduire les tests de collision couteux de la narrow phase.

3. Qu'est-ce que Rapier.js ?

Correct ! Rapier est un moteur physique open-source ecrit en Rust, compile en WASM pour le web. Il supporte rigid bodies, colliders, joints, et character controllers avec d'excellentes performances.
Incorrect. Rapier.js est un moteur physique Rust compile en WebAssembly, offrant des performances elevees pour la simulation physique dans le navigateur.

4. Pourquoi utilise-t-on un fixed timestep pour la simulation physique ?

Correct ! Un fixed timestep (ex: 1/60s) garantit que la physique se comporte identiquement quel que soit le framerate. Un delta variable causerait des tunneling, instabilites et non-determinisme.
Incorrect. Le fixed timestep garantit un comportement physique deterministe et stable, independant des variations de framerate.

5. Qu'est-ce que l'algorithme GJK (Gilbert-Johnson-Keerthi) ?

Correct ! GJK travaille sur la difference de Minkowski de deux formes convexes. Si l'origine est contenue dans cette difference, les formes se chevauchent. Il construit iterativement un simplexe pour le determiner.
Incorrect. GJK est un algorithme de narrow phase qui detecte l'intersection entre formes convexes via la difference de Minkowski et la construction iterative de simplexes.
