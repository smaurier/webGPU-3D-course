Quiz 07 — Shaders et textures

1. Qu'est-ce qu'un VBO (Vertex Buffer Object) ?

Correct ! Un VBO est un buffer alloue en memoire GPU qui contient les attributs des sommets (positions, normales, coordonnees UV, couleurs, etc.).
Incorrect. Un VBO est un buffer en memoire GPU stockant les donnees de sommets comme les positions, normales et coordonnees de texture.

2. Quelle est la difference entre un uniform et un attribute en GLSL ?

Correct ! Les attributes sont des donnees per-vertex (position, normale...) lues depuis les VBOs. Les uniforms sont constants pour tout le draw call (matrices, temps, couleur globale...).
Incorrect. Les attributes varient par sommet (lus depuis les VBOs), tandis que les uniforms restent constants pendant tout le draw call.

3. Que fait le filtrage bilineaire lors de l'echantillonnage d'une texture ?

Correct ! Le filtrage bilineaire interpole entre les 4 texels voisins les plus proches, produisant un rendu plus lisse que le filtrage nearest (point).
Incorrect. Le filtrage bilineaire interpole lineairement entre les 4 texels les plus proches de la coordonnee UV demandee.

4. A quoi servent les mipmaps ?

Correct ! Les mipmaps sont une chaine de versions reduites de la texture (chaque niveau divise par 2). Le GPU selectionne le niveau adapte a la taille a l'ecran, reduisant le moire et ameliorant les performances cache.
Incorrect. Les mipmaps sont des copies pre-calculees a resolutions decroissantes, utilisees quand la texture est vue de loin pour eviter l'aliasing et ameliorer les performances.

5. Qu'est-ce qu'un framebuffer object (FBO) en WebGL ?

Correct ! Un FBO permet de rediriger le rendu vers des textures ou renderbuffers au lieu de l'ecran. C'est essentiel pour le shadow mapping, le post-processing, et le rendu multi-passes.
Incorrect. Un FBO (Framebuffer Object) permet le rendu off-screen vers des textures, indispensable pour les effets multi-passes comme les ombres ou le post-processing.
