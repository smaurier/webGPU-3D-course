Quiz 16 — Post-processing

1. Quel est le role de l'EffectComposer dans Three.js ?

Correct ! L'EffectComposer gere une chaine de passes : chaque passe lit le resultat de la precedente et ecrit dans un framebuffer. La derniere passe ecrit a l'ecran.
Incorrect. L'EffectComposer chaine des passes de post-processing, chacune lisant le framebuffer precedent et ecrivant dans le suivant.

2. Comment fonctionne l'effet bloom ?

Correct ! Le bloom fonctionne en 3 etapes : extraction des zones lumineuses (threshold), flou gaussien multi-passe (souvent a resolution reduite), puis addition du resultat floute sur l'image originale.
Incorrect. Le bloom extrait les pixels lumineux, les floute, puis les ajoute a l'image originale pour creer un halo lumineux.

3. Que signifie SSAO (Screen Space Ambient Occlusion) ?

Correct ! SSAO echantillonne le depth buffer autour de chaque pixel pour estimer combien de geometrie proche l'occlude. Les zones encaissees (coins, plis) sont assombries, ajoutant de la profondeur visuelle.
Incorrect. SSAO estime l'occlusion ambiante en espace ecran via le depth buffer pour assombrir les creux et les coins de la geometrie.

4. A quoi sert le Raycaster dans Three.js ?

Correct ! Raycaster lance un rayon dans la scene et retourne les intersections triees par distance. Utilise pour le picking souris (convertir un clic 2D en selection 3D), les collisions, et la detection de visibilite.
Incorrect. Le Raycaster determine quels objets sont intersectes par un rayon, utilise pour le picking souris et la detection de collision.

5. Quel est le role de CSS2DRenderer ?

Correct ! CSS2DRenderer projette des elements DOM (CSS2DObject) dans l'espace 3D de la scene. Les elements HTML sont positionnes via CSS transform pour suivre les coordonnees 3D, ideals pour les labels et annotations.
Incorrect. CSS2DRenderer superpose des elements HTML positionnes dans l'espace 3D, utile pour les labels et tooltips qui suivent les objets 3D.
