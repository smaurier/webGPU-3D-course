Quiz 28 — Virtual Textures

1. Quel est le role de la page table dans un systeme de virtual textures ?

Correct ! La page table est une structure d'indirection : pour chaque page virtuelle (pageX, pageY, mip), elle stocke l'emplacement physique correspondant dans l'atlas texture en VRAM. Le shader la consulte pour transformer les UV virtuels en UV physiques.
Incorrect. La page table fait le lien entre les coordonnees virtuelles (UV + mip) et les emplacements physiques des tuiles dans l'atlas texture en VRAM.

2. Dans un cache LRU (Least Recently Used) pour les pages de texture, quelle page est evincee en premier quand le cache est plein ?

Correct ! Le LRU evince la page la moins recemment utilisee. C'est la strategie la plus courante pour les virtual textures car les pages visibles a l'ecran sont accedees frequemment et restent dans le cache.
Incorrect. LRU signifie Least Recently Used : la page qui n'a pas ete accedee depuis le plus longtemps est evincee en premier.

3. Comment le GPU determine-t-il quel mip level charger pour une page donnee lors du rendu ?

Correct ! Le feedback buffer (ou feedback pass) est un rendu a resolution reduite ou chaque pixel encode l'identifiant de la page virtuelle et le mip level requis. Le CPU analyse ensuite ce buffer pour savoir quelles pages charger.
Incorrect. Le feedback buffer est un rendu special qui ecrit, pour chaque pixel visible, les coordonnees de la page virtuelle et le mip level necessaire.

4. Qu'est-ce que Basis Universal ?

Correct ! Basis Universal est un format de texture supercompresse. Un seul fichier `.basis` ou `.ktx2` est distribue, puis transcode cote client vers le format GPU natif (BC7 sur desktop, ASTC sur mobile, ETC2 en fallback). Ideal pour le streaming de virtual textures.
Incorrect. Basis Universal est un format supercompresse transcodable vers BC7/ASTC/ETC2 selon le GPU, permettant de distribuer un seul fichier pour toutes les plateformes.

5. Qu'est-ce qu'un "page fault" dans un systeme de virtual textures ?

Correct ! Un page fault survient quand le shader a besoin d'une page qui n'est pas en VRAM. Le systeme utilise alors un mip level inferieur en fallback et planifie le chargement de la page manquante pour les frames suivantes.
Incorrect. Un page fault indique qu'une page demandee n'est pas dans le cache VRAM. Le systeme affiche un mip de substitution en attendant le chargement.
