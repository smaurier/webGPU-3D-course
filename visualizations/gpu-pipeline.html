Differences cles

AspectWebGLWebGPU
Paradigme Machine a etats globale Objets immutables + commandes
Langage shader GLSL (syntaxe C) WGSL (syntaxe Rust-like)
Ressources gl.bindBuffer, gl.uniform* Bind Groups explicites
Validation Au draw call (tard) A la creation du pipeline (tot)
Multi-thread Non (un seul contexte) Oui (command encoders paralleles)
Compute shaders Non supporte Supporte nativement
Gestion erreurs gl.getError() (codes numeriques) Messages explicites, error scopes
